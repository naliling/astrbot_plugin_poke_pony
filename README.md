## 一句话

**别人戳你一下，它还你一套完整的情绪系统。**

QQ 里双击头像戳一戳，机器人会「被戳得一激灵」、会回戳、会记仇；换到 Telegram、飞书、
企业微信、微信个人号，它照样能被「戳一戳」三个字唤醒——因为「戳」在这个插件里不再是一个
QQ 专属的协议事件，而是一层**跨平台的语义抽象**。

---

## 这个插件是怎么来的

它原本是别人送我的第一个定制插件，那会儿我还是个小白，只会照着改配置里的几行字。

后来 AstrBot 升级了，戳一戳事件从「通知事件」变成了「消息段」，老插件在群里被戳一下
就哑了火，偶尔还会甩一串报错出来。于是我把它整个拆开重写：保留那份「被戳了要有反应」的
初心，补上工程上该有的东西——多平台、降级、限流、统计、可观测性。

**它现在不只是一个能用的插件，而是一个可以直接拿去当模板的 AstrBot 插件工程范本。**

## 特性

### 🫵 原生戳一戳（QQ / OneBot）

- **双通道监听**：同时识别 `Poke` 消息段与 `notice.notify.poke` 通知事件，
  协议端怎么推送都能接住，并自动去重，不会一次戳回两条。
- **自动回戳**：群聊走 `group_poke`、私聊走 `friend_poke`，参数自动转 int，
  兼容 NapCat / Lagrange / LLOneBot 等主流协议端。
- **只戳自己**：默认只响应「戳机器人」的事件，群里 A 戳 B 时安静旁观，不刷屏。

### 🌐 全平台覆盖

| 平台 | 适配器 ID | 原生戳 | 本插件行为 |
| --- | --- | :---: | --- |
| QQ（OneBot v11） | `aiocqhttp` | ✅ | 原生监听 + 原生回戳 |
| QQ 官方机器人 | `qq_official` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| Telegram | `telegram` | ❌ | 触发词 / `/poke` + 拟真回戳 |
| 飞书 | `lark` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| 企业微信 | `wecom` / `wecom_ai_bot` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| 微信个人号 | `weixin_oc` | ❌ | 触发词 / `/戳` + 拟真「拍一拍」 |
| 微信公众号 | `weixin_official_account` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| 钉钉 / Discord / Slack / KOOK / LINE / Misskey / WebChat … | 对应 ID | ❌ | 兜底画像，开箱即用 |

> 没有原生戳能力的平台，会按平台文案发一条「👉 我 戳了戳 你」，微信系则用更贴切的
> 「👋 我 拍了拍 你」。**任何适配器**都有兜底画像，不存在「不支持」的平台。

### 🛡️ 三级回戳降级（本次修复的核心）

老版本直接调 `group_poke`，协议端一变就抛异常。新版本把回戳拆成三级：

```
原生 API (group_poke / friend_poke / send_poke)
        ↓ 失败
Poke 消息段（实验开关，可选）
        ↓ 失败
拟真文案（Telegram / 飞书 / 企微 / 微信 / QQ 官方 …）
```

**任何一级失败都会被吞掉并记入日志，永远不会把 traceback 甩到聊天窗口里。**
这就是「双击头像戳一戳会报错」的根治方案。

### 🎭 发言引擎

- 三种抽取模式：**权重随机** / **轮换** / **洗牌袋**（一轮内不重复，最均匀）。
- **变量插值**：`{sender}` `{count}` `{streak}` `{bot}` `{group}` `{time}` `{date}` `{platform}` …
- **连戳彩蛋**：45 秒内连戳达到阈值，自动切换到彩蛋模板——「喂喂喂，5 连戳了！手是租来的吗？」
- **联动模式**：独立 / 回戳时不发言 / 仅回戳时发言。
- **附带艾特**：支持 At 的平台会自动 @ 戳你的人。

### 🚦 防刷屏

- 用户冷却（默认 3 秒）
- 全局每分钟上限（默认 30 次）
- 事件去重窗口（默认 800ms）
- 安静时段（支持跨零点，例如 23:30 → 07:00）
- 群白名单 / 群黑名单 / 用户黑名单

### 📊 数据看板

- 今日 / 累计被戳次数、活跃人数、历史 14 天趋势
- `/戳榜` 排行榜，前三名有奖牌
- 数据通过 AstrBot 插件 KV 存储持久化，节流落盘，不额外产生文件

### 🤖 LLM 联动

内置函数工具 `poke_user`，开启后模型可以在对话里自己决定戳谁——
「提醒他交作业」不再是干巴巴的一句话，而是一记戳。

### ⌨️ 指令

| 指令 | 说明 |
| --- | --- |
| `/戳 @某人 [次数]` | 主动戳人，次数 1-10 |
| `/戳 用户ID 3` | 非 QQ 平台按 ID 戳（飞书 `ou_xxx` 也支持） |
| 回复某人的消息 + `/戳` | 戳被回复的人 |
| `/戳状态` | 运行状态、平台能力、今日数据 |
| `/戳榜` | 今日被戳排行榜 |
| `/戳帮助` | 使用说明 |

## 快速开始

1. 把 `astrbot_plugin_superpoke` 整个文件夹放进 AstrBot 的 `data/plugins/` 目录。
2. 打开 WebUI → 插件管理 → 重载插件（或重启 AstrBot）。
3. 在插件配置里按需调整「发言模板」「回戳设置」「平台适配」。
4. 让朋友双击你的头像戳一下，或者直接发一句「戳一戳」。

> 无需安装任何额外依赖，插件只用 AstrBot 内置 API 与 Python 标准库。

### 兼容性

- AstrBot `>= 4.13.0`（已在 **4.28.2** 上实测通过）
- Python 3.10+（AstrBot 桌面版自带环境即可）

## 配置速查

<details>
<summary><b>基础设置</b></summary>

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 总开关 | `true` | 关闭后不响应任何戳一戳 |
| 启用平台 | `[]` | 留空 = 全部平台 |
| 群聊启用 / 私聊启用 | `true` | 分场景开关 |
| 只响应戳机器人 | `true` | 群里 A 戳 B 时保持安静 |
| 机器人昵称 | `我` | 模板变量 `{bot}` |
| 用户冷却秒数 | `3` | 同一用户冷却 |
| 每分钟上限 | `30` | 全局限流 |
| 安静时段 | `23:30 → 07:00` | 跨零点免打扰 |
</details>

<details>
<summary><b>发言模板可用变量</b></summary>

| 变量 | 含义 |
| --- | --- |
| `{sender}` / `{sender_id}` | 戳你的人昵称 / ID |
| `{target}` / `{target_id}` | 被戳对象 |
| `{bot}` | 机器人昵称（可在基础设置里改） |
| `{group}` | 群号（私聊为空） |
| `{count}` | 该用户今日被戳次数 |
| `{streak}` | 当前连击数（45 秒窗口） |
| `{time}` / `{date}` | 当前时间 / 日期 |
| `{platform}` | 平台适配器 ID |

> 未知变量会原样保留，不会把整条发言变空白。
</details>

<details>
<summary><b>平台适配</b></summary>

每个平台可以单独覆盖：

- `原生回戳`：是否调用平台原生接口
- `支持艾特`：是否支持 At 消息段
- `拟真文案`：降级时发什么（支持变量）
- `表情前缀`：文案前的点缀表情

新增平台时不用改代码——在配置里加一个同名小节即可。
</details>

## 常见问题

**Q：戳了没反应？**
1. 看 `/戳状态` 是否显示平台能力与开关正常；
2. 检查「启用平台」是否把当前平台排除在外；
3. 检查群白名单 / 黑名单；
4. 检查是否处于安静时段；
5. 看日志里有没有 `[新·戳一戳] 触发全局每分钟上限` —— 那是限流生效了。

**Q：为什么群里 A 戳 B 机器人不理？**
默认「只响应戳机器人」是开着的，这是防刷屏设计。关掉它就会跟着掺和。

**Q：Telegram / 飞书 上怎么戳？**
发「戳一戳」「戳戳」「拍一拍」「戳我」任一个，或者用 `/戳 @某人`。
触发词可以在「指令设置」里随便改。

**Q：会不会把号戳出问题？**
原生回戳带间隔（默认 300ms）与次数上限（10 次），加上用户冷却和每分钟上限，
正常使用不会触发风控。仍然建议不要把「回戳次数」调到 10 以上。

**Q：统计数据存在哪？**
AstrBot 的插件 KV 存储里（key 为 `poke_stats_v2`），卸载插件时可在 WebUI 里一并清理。

## 工程结构

```
astrbot_plugin_superpoke/
├── main.py                 # 插件入口：事件监听、指令、LLM 工具
├── poke_core/
│   ├── settings.py         # 配置解析 + 平台能力画像
│   ├── detect.py           # 跨平台戳一戳识别（鸭子类型，版本无关）
│   ├── backends.py         # 三级回戳降级执行器
│   ├── templates.py        # 发言模板引擎（权重/轮换/洗牌袋）
│   ├── stats.py            # 统计、连击、排行榜（KV 持久化）
│   └── ratelimit.py        # 冷却与限流
├── tests/
│   ├── smoke_test.py       # 30 项断言，覆盖识别/回戳/降级/指令/冷却
│   └── load_test.py        # 模拟 AstrBot 真实加载路径与 schema 构建
├── _conf_schema.json       # WebUI 配置表单
├── metadata.yaml
└── requirements.txt
```

### 跑测试

```bash
# 用 AstrBot 自带的 Python 环境
python tests/smoke_test.py
python tests/load_test.py
```

`smoke_test.py` 用真实的 `AiocqhttpMessageEvent` 与伪协议端驱动插件，断言
「发言是否产生」「是否调用 group_poke」「原生失败是否降级」「冷却是否生效」等；
`load_test.py` 则把插件复制到临时目录，按 `data.plugins.<name>.main` 的路径导入，
验证相对导入、`metadata.yaml` 校验与 `_conf_schema.json` 构建。
