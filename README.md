# 新.戳一戳

> **这不是又一个戳一戳。**
> 真正自定义 —— 台词、触发词、平台、阈值全你说了算，插件一句台词都不预设；
> 配置少不操心 —— 装上只填两处就能跑，其余默认值已经调好。

## 它做什么

别人戳你一下，机器人会**有反应**：

- **QQ 里双击头像戳一戳** → 它说话、回戳、记仇；
- **Telegram / 飞书 / 企业微信 / 微信个人号** 没有原生戳 → 发一句「戳一戳」也能触发；
- 戳太多 → 它会嫌烦，**自己安静下来**（可选怼你一句）；
- 想让它说点应景的 → 打开 **LLM 台词**，它会按当下的情绪和好感度现编一句。

一句话：**把「戳」这件事，从 QQ 的一个协议事件，做成了所有平台通用的情绪入口。**

## 怎么用（三十秒）

**1. 装上**

把 `astrbot_plugin_poke_pony` 整个文件夹放进 `AstrBot/data/plugins/`，然后重载插件。

**2. 填两处**

| 填哪里 | 填什么 | 例子 |
| --- | --- | --- |
| 发言设置 → 发言模板 | 被戳时说的话 | `（被戳了）干嘛呀` |
| 平台适配 → 你的平台 → 拟真文案 | 回戳时发的动作 | `{bot} 戳了戳 {target}` |

> 就这两处。**其他 60 多项都不用动**——默认值已经调到「不会被风控、不会刷屏」的区间。
> QQ 用户甚至可以连第二处都不填，原生回戳不需要任何文案。

**3. 用起来**

- 别人戳你 / 发「戳一戳」→ 它自动回应
- 你想主动戳人 → `/戳 @某人`、`/戳 @某人 3`、或回复某人消息后 `/戳`
- 看它今天怎么样 → `/戳状态`；看谁最烦 → `/戳榜`

**4. 想让它更像「她」**

- 打开「LLM 生成」，台词就变成现场生成（带超时、字数、每分钟配额三重保险）；
- 打开「人形化联动」，接上 humanoid_core —— **她睡着时不会理你**。

## 特性

### 🫵 原生戳一戳（QQ / OneBot）

- **双通道监听**：`Poke` 消息段与 `notice.notify.poke` 通知事件都认，协议端怎么推都能接住，自动去重，不会一次戳回两条；
- **自动回戳**：群聊 `group_poke`、私聊 `friend_poke`，参数自动转 int，兼容 NapCat / Lagrange / LLOneBot；
- **只戳自己**：默认只响应「戳机器人」，群里 A 戳 B 时安静旁观。

### 🌐 全平台 + 自定义平台

| 平台 | 适配器 ID | 原生戳 |
| --- | --- | :---: |
| QQ（OneBot v11） | `aiocqhttp` | ✅ |
| QQ 官方机器人 | `qq_official` | ❌ 触发词 |
| Telegram | `telegram` | ❌ 触发词 |
| 飞书 | `lark` | ❌ 触发词 |
| 企业微信 | `wecom` / `wecom_ai_bot` | ❌ 触发词 |
| 微信个人号 / 公众号 | `weixin_oc` / `weixin_official_account` | ❌ 触发词 |
| 钉钉 / Discord / Slack / KOOK / LINE / Misskey / WebChat / Matrix / VoceChat | 对应 ID | ❌ 兜底画像 |

**没内置的适配器？** 「自定义平台」加一条（平台 ID / 是否原生回戳 / 是否支持 @ / 拟真文案），立刻能用，不用等更新。

### 🛡️ 三级回戳降级

```
原生 API (group_poke / friend_poke / send_poke)
        ↓ 失败
Poke 消息段（实验开关）
        ↓ 失败 / 平台不支持
拟真文案
```

**任何一级失败都只写日志，永远不会把报错甩到聊天窗口。**

### 🎭 发言引擎

权重随机 / 轮换 / 洗牌袋三种抽取模式；支持 `{sender}` `{count}` `{streak}` `{bot}` `{group}` `{time}` `{date}` `{platform}` 变量；45 秒连击彩蛋；发言与回戳的联动模式可选。

### 🤖 LLM 现场生成台词（可选）

被戳时先让模型按情境生成一句，三重保险：**超时 10s / 字数上限 40 / 每分钟配额 5 次**。模型不可用、返回空、超时、报错 —— 全部静默回退模板，用户只会看到正常回应。

### 🚦 防骚扰（只静默，不拉黑）

同一人 **60 秒内被戳超过阈值（默认 5 次）** 就触发：

- `静默不回应`（默认）：不说话、不回戳，窗口滑过自动恢复；
- `静默并怼人`：先发一条你自己写的怼人文案，再静默；
- `只怼人`：照常回应，额外怼一句。

**不拉黑、不禁言、不通知别人**，只是一句「别戳了」的软提醒。

### 💞 人形化联动（只读）

装了 [humanoid_core](https://github.com/naliling/humanoid_core_plugin) 时，只读它导出的**版本化契约**（`contract` v1，字段只加不改）：她睡着时不回应；体感 / 体力 / 正在做什么 / 对你的好感度会带进 LLM 提示词。没装、关掉、路径不对 —— 静默跳过，不影响任何功能。

### 📊 数据看板

今日 / 累计被戳次数、活跃人数、`/戳榜` 排行榜，KV 持久化 + 节流落盘，不产生额外文件。

### ⌨️ 指令

| 指令 | 说明 |
| --- | --- |
| `/戳 @某人 [次数]` | 主动戳人，次数 1-10 |
| `/戳 用户ID 3` | 非 QQ 平台按 ID 戳 |
| 回复某人消息 + `/戳` | 戳被回复的人 |
| `/戳状态` | 运行状态、平台能力、人形化状态、今日数据 |
| `/戳榜` | 今日被戳排行榜 |
| `/戳帮助` | 使用说明 |

## 为什么是「真正自定义」

| 你想要的 | 这里怎么给 |
| --- | --- |
| 换台词 | WebUI 里加/删，改完立刻生效，不用重启 |
| 换触发词 | 「指令设置 → 触发词」随便改，中英都行 |
| 换平台 | 「平台适配」逐平台覆盖，或用「自定义平台」加新的 |
| 换阈值 | 冷却、每分钟、防骚扰阈值、怼人冷却，全在「防骚扰」一页里 |
| 换语气 | 开 LLM，写一句系统提示就换人设 |

**插件不替你做任何「它觉得好」的决定**：不预设台词、不预设语气、不预设谁该被拉黑。

## 配置速查

11 个分组，每一项都有 hint。这里只列最常改的：

<details>
<summary><b>基础设置</b></summary>

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 总开关 | `true` | 关闭后不响应任何戳一戳 |
| 启用平台 | `[]` | 留空 = 全部平台 |
| 群聊启用 / 私聊启用 | `true` | 分场景开关 |
| 只响应戳机器人 | `true` | 群里 A 戳 B 时保持安静 |
| 机器人昵称 | `我` | 模板变量 `{bot}` |
| 用户冷却秒数 | `3` | 同一用户冷却 |
| 安静时段 | `23:30 → 07:00` | 跨零点免打扰 |
</details>

<details>
<summary><b>模板变量</b></summary>

| 变量 | 含义 |
| --- | --- |
| `{sender}` / `{sender_id}` | 戳你的人昵称 / ID |
| `{target}` / `{target_id}` | 被戳对象 |
| `{bot}` | 机器人昵称 |
| `{group}` | 群号（私聊为空） |
| `{count}` | 该用户今日被戳次数 |
| `{streak}` | 当前连击数（45 秒窗口） |
| `{time}` / `{date}` | 当前时间 / 日期 |
| `{platform}` | 平台适配器 ID |

> 未知变量会原样保留，不会把整条发言变空白。
</details>

<details>
<summary><b>防骚扰 / LLM / 人形化</b></summary>

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 防骚扰开关 | `true` | 关掉后只剩冷却与全局限流 |
| 每分钟阈值 | `5` | 同一人 60 秒内超过几次触发 |
| 触发动作 | `静默不回应` | 静默 / 静默并怼人 / 只怼人 |
| 怼人模板 | `[]` | 自己写，留空则只静默 |
| LLM台词开关 | `false` | 开启后优先用模型生成 |
| LLM每分钟上限 | `5` | 全局配额，0 = 不用 |
| 联动开关 | `false` | 读取 humanoid_core 契约 |
| 睡着时不回应 | `true` | `body.asleep = true` 时直接静默 |
</details>

## 常见问题

**Q：戳了没反应？**
1. 先看 `/戳状态`，确认总开关、平台能力、模板条数；
2. **发言模板是空的就不会说话**——插件不预设台词，这是设计如此；
3. 检查「启用平台」「群白名单/黑名单」；
4. 检查是否处于安静时段；
5. 日志里出现 `超过阈值` 说明被防骚扰静默了；出现 `全局每分钟上限` 说明被限流了。

**Q：为什么默认一句话都不说？**
因为戳一戳该说什么取决于你的角色。插件只负责「什么时候说、说几条、说多长」，台词留给你。

**Q：防骚扰会不会把人拉黑？**
不会。它只在一个 60 秒滑动窗口里数次数，超过就这一次不回应（可选怼一句），窗口滑过自动恢复，不写任何黑名单。

**Q：LLM 会不会把号刷爆？**
有每分钟配额（默认 5 次）+ 概率 + 超时回退，最坏也只是回退到模板。群多时建议把配额调到 3 以下。

**Q：人形化联动读不到数据？**
`/戳状态` 会显示「没读到契约」。检查 humanoid_core 是否启用、`contract_enabled` 是否被关掉，或直接在「状态文件路径」里手填完整路径。

## 和其他戳一戳插件比

只说事实，不贬低谁：

- 多数戳一戳插件把「说什么」写进代码或默认配置，想改成自己的语气得翻源码；
  **这个插件一句台词都不预设**，全部由你在 WebUI 里加。
- 不少插件要配一堆开关才能跑起来；**这个插件装上只填两处**，其余默认值已经在
  「不被风控、不刷屏」的区间。
- 多数插件只做 QQ；**这个插件内置 20 个平台画像 + 自定义平台**，新适配器填一条就能用。
- 被戳太多时，常见做法是要么一直回、要么直接拉黑；**这个插件按分钟阈值自动静默**，
  不拉黑、不禁言，窗口过去自动恢复。
- 有些插件原生接口失败会把异常抛到聊天窗口；**这个插件三级降级，失败只写日志**。

当然它也有代价：**台词要你自己写**（我们坚持不替你做这个决定），
LLM 台词会消耗 token（有配额但仍是成本），人形化联动需要另一个插件配合。
**它不试图做全家桶，只把「戳」这一件事做干净。**
