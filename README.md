## 一句话

**别人戳你一下，它还你一套完整的情绪系统。**

QQ 里双击头像戳一戳，机器人会「被戳得一激灵」、会回戳、会记仇；换到 Telegram、飞书、
企业微信、微信个人号，它照样能被「戳一戳」三个字唤醒——因为「戳」在这个插件里不再是一个
QQ 专属的协议事件，而是一层**跨平台的语义抽象**。

---

## 这个插件是怎么来的

它原本是别人送我的第一个定制插件，那会儿我还是个小白，只会照着改配置里的几行字。

后来 AstrBot 升级了，戳一戳事件从「通知事件」变成了「消息段」，老插件在群里被戳一下
就哑了火，偶尔还会甩一串报错出来。于是我把它整个拆开重写：保留那份「被戳了要有反应」的
初心，补上工程上该有的东西——多平台、降级、限流、统计、可观测性。

**它现在不只是一个能用的插件，而是一个可以直接拿去当模板的 AstrBot 插件工程范本。**

---

## ⚠️ 开箱是「空的」

插件**不预设任何台词**：发言模板、连击彩蛋、怼人文案默认都是空列表，拟真文案也留空。
装上之后的行为是：**QQ 上被戳就戳回去，一句话都不说**；其他平台需要你先写拟真文案。

这是刻意的——戳一戳该说什么，是每个角色自己的事。配置里每一项都写了 hint，
照着填就行。想立刻听到反应，最省事的做法是：

1. 「发言设置 → 发言模板」加一条，例如 `（被戳了）干嘛呀`
2. 「平台适配 → 你的平台 → 拟真文案」填 `{bot} 戳了戳 {target}`

## 特性

### 🫵 原生戳一戳（QQ / OneBot）

- **双通道监听**：同时识别 `Poke` 消息段与 `notice.notify.poke` 通知事件，
  协议端怎么推送都能接住，并自动去重，不会一次戳回两条。
- **自动回戳**：群聊走 `group_poke`、私聊走 `friend_poke`，参数自动转 int，
  兼容 NapCat / Lagrange / LLOneBot 等主流协议端。
- **只戳自己**：默认只响应「戳机器人」的事件，群里 A 戳 B 时安静旁观，不刷屏。

### 🌐 全平台 + 自定义平台

| 平台 | 适配器 ID | 原生戳 | 本插件行为 |
| --- | --- | :---: | --- |
| QQ（OneBot v11） | `aiocqhttp` | ✅ | 原生监听 + 原生回戳 |
| QQ 官方机器人 | `qq_official` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| Telegram | `telegram` | ❌ | 触发词 / `/poke` + 拟真回戳 |
| 飞书 | `lark` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| 企业微信 | `wecom` / `wecom_ai_bot` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| 微信个人号 | `weixin_oc` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| 微信公众号 | `weixin_official_account` | ❌ | 触发词 / `/戳` + 拟真回戳 |
| 钉钉 / Discord / Slack / KOOK / LINE / Misskey / WebChat / Matrix / VoceChat … | 对应 ID | ❌ | 兜底画像，开箱即用 |

**还没内置的适配器？** 在「自定义平台」里加一条：填平台 ID、是否原生回戳、是否支持 @、
拟真文案，立刻就能用，不用改代码、不用等更新。

### 🛡️ 三级回戳降级

```
原生 API (group_poke / friend_poke / send_poke)
        ↓ 失败
Poke 消息段（实验开关，可选）
        ↓ 失败 / 平台不支持
拟真文案（Telegram / 飞书 / 企微 / 微信 / QQ 官方 …）
```

**任何一级失败都会被吞掉并记入日志，永远不会把 traceback 甩到聊天窗口里。**

### 🎭 发言引擎

- 三种抽取模式：**权重随机** / **轮换** / **洗牌袋**（一轮内不重复，最均匀）。
- **变量插值**：`{sender}` `{count}` `{streak}` `{bot}` `{group}` `{time}` `{date}` `{platform}` …
- **连戳彩蛋**：45 秒内连戳达到阈值，自动切换到彩蛋模板。
- **联动模式**：独立 / 回戳时不发言 / 仅回戳时发言。
- **附带艾特**：支持 At 的平台会自动 @ 戳你的人。

### 🤖 LLM 现场生成台词（可选）

打开后，被戳时先让模型现场生成一句，带三重保险：

- **超时**：默认 10 秒，超时立刻回退模板，消息不会卡住；
- **字数上限**：默认 40 字，超出截断；
- **每分钟配额**：默认 5 次，用完了自动走模板，不会被戳到破产。

模型不可用 / 返回空 / 抛异常 → 全部静默回退模板，用户只会看到正常的回应。

### 🚦 防骚扰（只静默，不拉黑）

同一人 **60 秒内被戳超过阈值（默认 5 次）** 就触发：

- `静默不回应`（默认）：不说话、也不回戳，窗口滑过去自动恢复；
- `静默并怼人`：先发一条你自己写的怼人文案，再静默；
- `只怼人`：照常回应，额外怼一句。

**不会拉黑、不会禁言、不会通知别人**——它只是一条「别戳了」的软提醒。
怼人文案默认是空的，要怼得自己写。

### 💞 人形化联动（只读）

如果装了 [humanoid_core](https://github.com/naliling/humanoid_core_plugin)，可以只读它
导出的**版本化契约**（`state.json` 里的 `roles[bot].self.contract`，`v1`，字段只加不改）：

- 她**睡着时**不回应（可关）；
- 她的**体感 / 体力 / 正在做什么 / 对你的好感度**会带进 LLM 提示词，
  生成出来的台词就不再是「一个没有身体的机器人」在说话；
- `/戳状态` 里能看到她此刻的状态。

没装、关掉了契约、路径不对 —— 全部静默跳过，不影响任何功能。

> 为什么不接 `autonomous_social`？它的 `state.json` 只有内部结构（`version: 2`），
> 没有像 humanoid_core 那样的对外契约（`contract` + 版本号 + 文档化的 paths）。
> 直接读别人的私有结构，对方一改字段就会崩，所以**这条联动没有做**。

### 📊 数据看板

- 今日 / 累计被戳次数、活跃人数、历史 14 天趋势
- `/戳榜` 排行榜，前三名有奖牌
- 数据通过 AstrBot 插件 KV 存储持久化，节流落盘，不额外产生文件

### ⌨️ 指令

| 指令 | 说明 |
| --- | --- |
| `/戳 @某人 [次数]` | 主动戳人，次数 1-10 |
| `/戳 用户ID 3` | 非 QQ 平台按 ID 戳（飞书 `ou_xxx` 也支持） |
| 回复某人的消息 + `/戳` | 戳被回复的人 |
| `/戳状态` | 运行状态、平台能力、人形化状态、今日数据 |
| `/戳榜` | 今日被戳排行榜 |
| `/戳帮助` | 使用说明 |

## 快速开始

1. 把 `astrbot_plugin_poke_pony` 整个文件夹放进 AstrBot 的 `data/plugins/` 目录。
2. 打开 WebUI → 插件管理 → 重载插件（或重启 AstrBot）。
3. 去「发言设置」写一条台词，去「平台适配」写一条拟真文案。
4. 让朋友双击你的头像戳一下，或者直接发一句「戳一戳」。

> 无需安装任何额外依赖，插件只用 AstrBot 内置 API 与 Python 标准库。

### 关于名字

- 显示名（WebUI 里看到的）是 **新.戳一戳**
- 插件 ID 是 `娜莉灵/astrbot_plugin_poke_pony`
- 目录名是 `astrbot_plugin_poke_pony`，和 metadata 的 `name` 一致

AstrBot 用目录名拼接 Python 导入路径（`data.plugins.<目录名>.main`），
所以目录名不能带 `.`；中文名放在 `display_name` 里，两者不冲突。

### 兼容性

- AstrBot `>= 4.13.0`（已在 **4.28.2** 上实测通过）
- Python 3.10+（AstrBot 桌面版自带环境即可）

## 常见问题

**Q：戳了没反应？**
1. 先看 `/戳状态`，确认总开关、平台能力、模板条数；
2. 发言模板是空的就不会说话——这是设计如此；
3. 检查「启用平台」「群白名单/黑名单」；
4. 检查是否处于安静时段；
5. 日志里出现 `超过阈值` 说明被防骚扰静默了；出现 `全局每分钟上限` 说明被限流了。

**Q：为什么默认一句话都不说？**
因为戳一戳该说什么取决于你的角色。插件只负责「什么时候说、说几条、说多长」，
台词留给你。

**Q：防骚扰会不会把人拉黑？**
不会。它只在一个 60 秒滑动窗口里数次数，超过就这一次不回应（可选怼一句），
窗口滑过去自动恢复，不写任何黑名单。

**Q：LLM 会不会把号刷爆？**
有每分钟配额（默认 5 次）+ 概率 + 超时回退，最坏情况也只是回退到模板。
建议群多的时候把配额调到 3 以下。

**Q：人形化联动读不到数据？**
在 `/戳状态` 里会显示「没读到契约」。检查 humanoid_core 是否启用、契约是否被关掉
（它的配置里有 `contract_enabled`），或者直接在「状态文件路径」里手填完整路径。

**Q：统计数据存在哪？**
AstrBot 的插件 KV 存储里（key 为 `poke_stats_v2`），卸载插件时可在 WebUI 里一并清理。

## 工程结构

```
astrbot_plugin_poke_pony/
├── main.py                 # 插件入口：事件监听、指令、LLM 台词、防骚扰
├── logo.png                # 插件图标（WebUI 插件卡片显示）
├── poke_core/
│   ├── settings.py         # 配置解析 + 平台能力画像 + 自定义平台
│   ├── detect.py           # 跨平台戳一戳识别（鸭子类型，版本无关）
│   ├── backends.py         # 三级回戳降级执行器
│   ├── templates.py        # 发言模板引擎（权重/轮换/洗牌袋）
│   ├── stats.py            # 统计、连击、排行榜（KV 持久化）
│   ├── ratelimit.py        # 冷却、防骚扰滑动窗口、全局限流
│   └── humanoid.py         # 只读 humanoid_core 的版本化契约
├── tests/
│   ├── smoke_test.py       # 52 项断言：识别/回戳/降级/指令/防骚扰/LLM/人形化/自定义平台
│   └── load_test.py        # 26 项断言：真实加载路径、schema 构建、热重载
├── original/               # 原版 astrbot_plugin_poke 存档
├── _conf_schema.json       # WebUI 配置表单（11 个分组，每项都有 hint）
├── metadata.yaml
└── requirements.txt
```

### 跑测试

```bash
# 用 AstrBot 自带的 Python 环境
python tests/smoke_test.py
python tests/load_test.py
```
